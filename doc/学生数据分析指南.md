# 学生数据分析指南

## 一、数据库结构分析

### 核心表结构

#### 1. 学生相关表
- **students**：存储学生基本信息
  - 字段：id, student_id(学号), password, name, grade, major, created_at
- **student_class**：学生与班级的多对多关联
  - 字段：id, student_id, class_id, created_at

#### 2. 课程相关表
- **courses**：课程信息
  - 字段：id, course_id, course_name, credit, created_at
- **class_course**：班级与课程的多对多关联
  - 字段：id, class_id, course_id, created_at

#### 3. 学习行为相关表
- **course_videos**：课程视频信息
  - 字段：id, course_id, video_url, title, duration, order_index, created_at
- **video_play_duration**：学生观看视频时长记录
  - 字段：id, student_id, video_id, duration(秒), created_at
- **video_comments**：学生对视频的评论和评分
  - 字段：id, video_id, student_id, content, rating(1-5分), created_at

#### 4. 教学互动相关表
- **course_attendance**：课程签到活动
  - 字段：id, course_id, teacher_id, title, code, start_time, end_time, created_at
- **attendance_records**：学生签到记录
  - 字段：id, attendance_id, course_id, student_id, check_in_time, status
- **course_resources**：课程资源
  - 字段：id, course_id, teacher_id, resource_url, title, description, resource_type, created_at
- **resource_downloads**：学生下载资源记录
  - 字段：id, resource_id, student_id, download_time
- **discussion_topics**：课程讨论话题
  - 字段：id, course_id, teacher_id, title, content, created_at
- **topic_comments**：学生对讨论话题的评论
  - 字段：id, topic_id, student_id, content, created_at
- **assignment_topics**：课程作业主题
  - 字段：id, course_id, teacher_id, title, content, start_time, end_time, created_at
- **assignments**：学生提交的作业
  - 字段：id, assignment_topic_id, student_id, content, submit_time, score, status

## 二、可用于分析学生状况的数据

### 1. 学生基本信息分析
- **学生人口统计学特征**：年级、专业分布
- **学生基础信息**：学号、姓名等基本标识信息

### 2. 学习行为分析
- **视频观看行为**：
  - 观看时长统计（总时长、平均时长）
  - 观看频率和时间段分布
  - 视频完成率（观看时长/视频总时长）
  - 视频评分分布
- **资源下载行为**：
  - 下载资源的数量和类型
  - 下载时间分布
- **作业提交行为**：
  - 作业提交时间（是否按时）
  - 作业质量（分数）
  - 作业完成率

### 3. 课堂参与度分析
- **签到情况**：
  - 签到率
  - 签到时间（是否准时）
  - 缺勤情况
- **讨论参与**：
  - 评论数量
  - 评论内容质量（可通过NLP分析）
  - 讨论活跃度

### 4. 学习成绩分析
- **作业分数分布**：
  - 平均分
  - 分数趋势
  - 分数与其他行为的相关性

### 5. 综合学习状况评估
- **学习投入度**：结合视频观看、资源下载、讨论参与等指标
- **学习习惯**：时间管理、学习频率等
- **学习效果**：作业成绩、课程参与度等综合评估

## 三、深度学习在学生数据分析中的应用

### 1. 预测模型
- **学习成绩预测**：
  - 基于历史学习行为数据预测未来成绩
  - 特征：观看时长、资源下载量、讨论参与度、作业提交情况等
  - 模型：线性回归、决策树、神经网络

- ** dropout 风险预测**：
  - 识别可能辍学的学生
  - 特征：学习活跃度、作业完成率、签到率等
  - 模型：分类算法（随机森林、SVM、深度学习分类器）

### 2. 行为分析模型
- **学习行为模式识别**：
  - 聚类分析学生学习行为模式
  - 识别不同类型的学习者（如积极型、被动型、规律型等）
  - 模型：K-means聚类、层次聚类、DBSCAN

- **异常行为检测**：
  - 识别异常的学习行为（如突然学习活跃度下降）
  - 模型：自编码器、孤立森林、One-Class SVM

### 3. 自然语言处理应用
- **评论情感分析**：
  - 分析学生对视频和讨论的评论情感
  - 模型：LSTM、BERT、情感分析模型

- **作业内容分析**：
  - 评估作业质量和内容深度
  - 模型：文本分类、主题模型

### 4. 时间序列分析
- **学习行为趋势分析**：
  - 分析学生学习行为随时间的变化
  - 模型：LSTM、GRU、时间序列预测模型

- **学习习惯模式挖掘**：
  - 识别学生的学习时间模式（如晨型人、夜猫子）
  - 模型：时间序列聚类、模式识别算法

### 5. 多模态数据融合
- **整合多种数据源**：
  - 结合视频观看数据、文本评论、作业成绩等多维度数据
  - 模型：多模态融合模型、注意力机制

### 6. 个性化学习推荐
- **基于深度学习的推荐系统**：
  - 根据学生历史行为推荐适合的学习资源
  - 模型：协同过滤、深度学习推荐模型

## 七、gRPC预测服务集成

### 1. 服务可用性分析

经过分析，当前数据库结构完全支持使用gRPC预测服务，因为数据库中已经包含了计算所有必要指标的数据：

- **音视频学习完成率**：可通过 `video_play_duration` 和 `course_videos` 表计算
- **资料自主学习完成率**：可通过 `resource_downloads` 和 `course_resources` 表计算
- **章节学习次数**：可通过 `video_play_duration` 表计算
- **讨论参与度**：可通过 `topic_comments` 和 `discussion_topics` 表计算
- **签到完成率**：可通过 `attendance_records` 和 `course_attendance` 表计算

### 2. 数据查询语句

#### 2.1 音视频学习完成率

```sql
WITH video_total_duration AS (
    SELECT 
        cv.course_id,
        SUM(CASE WHEN cv.duration ~ '^[0-9]+:[0-9]+$' 
            THEN (SPLIT_PART(cv.duration, ':', 1)::int * 60) + SPLIT_PART(cv.duration, ':', 2)::int
            ELSE 0 END) as total_seconds
    FROM course_videos cv
    GROUP BY cv.course_id
),
student_watch_duration AS (
    SELECT 
        vpd.student_id,
        cv.course_id,
        SUM(vpd.duration) as watch_seconds
    FROM video_play_duration vpd
    JOIN course_videos cv ON vpd.video_id = cv.id
    GROUP BY vpd.student_id, cv.course_id
)
SELECT 
    swd.student_id,
    swd.course_id,
    ROUND((swd.watch_seconds::float / vtd.total_seconds) * 100, 2) as video_learning
FROM student_watch_duration swd
JOIN video_total_duration vtd ON swd.course_id = vtd.course_id;
```

#### 2.2 资料自主学习完成率

```sql
WITH total_resources AS (
    SELECT 
        course_id,
        COUNT(*) as total_count
    FROM course_resources
    GROUP BY course_id
),
student_downloads AS (
    SELECT 
        rd.student_id,
        cr.course_id,
        COUNT(*) as download_count
    FROM resource_downloads rd
    JOIN course_resources cr ON rd.resource_id = cr.id
    GROUP BY rd.student_id, cr.course_id
)
SELECT 
    sd.student_id,
    sd.course_id,
    ROUND((sd.download_count::float / tr.total_count) * 100, 2) as material_learning
FROM student_downloads sd
JOIN total_resources tr ON sd.course_id = tr.course_id;
```

#### 2.3 章节学习次数

```sql
SELECT 
    student_id,
    cv.course_id,
    COUNT(DISTINCT vpd.video_id) as chapter_study_count
FROM video_play_duration vpd
JOIN course_videos cv ON vpd.video_id = cv.id
GROUP BY student_id, cv.course_id;
```

#### 2.4 讨论参与度

```sql
WITH total_topics AS (
    SELECT 
        course_id,
        COUNT(*) as total_count
    FROM discussion_topics
    GROUP BY course_id
),
student_comments AS (
    SELECT 
        tc.student_id,
        dt.course_id,
        COUNT(*) as comment_count
    FROM topic_comments tc
    JOIN discussion_topics dt ON tc.topic_id = dt.id
    GROUP BY tc.student_id, dt.course_id
)
SELECT 
    sc.student_id,
    sc.course_id,
    ROUND((sc.comment_count::float / tt.total_count) * 100, 2) as discussion
FROM student_comments sc
JOIN total_topics tt ON sc.course_id = tt.course_id;
```

#### 2.5 签到完成率

```sql
WITH total_attendances AS (
    SELECT 
        course_id,
        COUNT(*) as total_count
    FROM course_attendance
    GROUP BY course_id
),
student_attendances AS (
    SELECT 
        ar.student_id,
        ar.course_id,
        COUNT(*) as attendance_count
    FROM attendance_records ar
    WHERE ar.status = '已签到'
    GROUP BY ar.student_id, ar.course_id
)
SELECT 
    sa.student_id,
    sa.course_id,
    ROUND((sa.attendance_count::float / ta.total_count) * 100, 2) as attendance
FROM student_attendances sa
JOIN total_attendances ta ON sa.course_id = ta.course_id;
```

### 3. 集成方法

#### 3.1 数据获取流程

1. **按学生和课程获取指标**：使用上述SQL查询获取每个学生在每门课程的五个指标
2. **数据预处理**：确保所有指标值在0-100范围内，处理缺失值
3. **调用gRPC服务**：将处理后的数据发送到gRPC服务进行预测
4. **获取预测结果**：接收并存储预测的成绩等级和置信度

#### 3.2 gRPC服务调用示例（TypeScript）

以下示例展示了如何使用TypeScript从数据库获取数据并调用gRPC服务：

```typescript
import { Client } from 'pg';
import * as grpc from '@grpc/grpc-js';
import * as protoLoader from '@grpc/proto-loader';

// 加载gRPC协议定义
const PROTO_PATH = './proto/student_analysis.proto';
const packageDefinition = protoLoader.loadSync(PROTO_PATH, {
  keepCase: true,
  longs: String,
  enums: String,
  defaults: true,
  oneofs: true
});

const studentAnalysisProto = grpc.loadPackageDefinition(packageDefinition) as any;

// 数据库连接配置
const dbConfig = {
  user: 'vibe_user',
  host: 'localhost',
  database: 'vibe_db',
  password: 'vibe_password',
  port: 5432,
};

// 创建数据库客户端
const db = new Client(dbConfig);

// 连接数据库
async function connectDB() {
  try {
    await db.connect();
    console.log('数据库连接成功');
  } catch (error) {
    console.error('数据库连接失败:', error);
    process.exit(1);
  }
}

// 从数据库获取学生指标
async function getStudentMetrics(studentId: string, courseId: string) {
  // 查询音视频学习完成率
  const videoLearningQuery = `
    WITH video_total_duration AS (
        SELECT 
            cv.course_id,
            SUM(CASE WHEN cv.duration ~ '^[0-9]+:[0-9]+$' 
                THEN (SPLIT_PART(cv.duration, ':', 1)::int * 60) + SPLIT_PART(cv.duration, ':', 2)::int
                ELSE 0 END) as total_seconds
        FROM course_videos cv
        WHERE cv.course_id = $1
        GROUP BY cv.course_id
    ),
    student_watch_duration AS (
        SELECT 
            vpd.student_id,
            cv.course_id,
            SUM(vpd.duration) as watch_seconds
        FROM video_play_duration vpd
        JOIN course_videos cv ON vpd.video_id = cv.id
        WHERE vpd.student_id = $2 AND cv.course_id = $1
        GROUP BY vpd.student_id, cv.course_id
    )
    SELECT 
        ROUND((swd.watch_seconds::float / vtd.total_seconds) * 100, 2) as video_learning
    FROM student_watch_duration swd
    JOIN video_total_duration vtd ON swd.course_id = vtd.course_id
    WHERE swd.student_id = $2 AND swd.course_id = $1
  `;

  // 查询资料自主学习完成率
  const materialLearningQuery = `
    WITH total_resources AS (
        SELECT 
            course_id,
            COUNT(*) as total_count
        FROM course_resources
        WHERE course_id = $1
        GROUP BY course_id
    ),
    student_downloads AS (
        SELECT 
            rd.student_id,
            cr.course_id,
            COUNT(*) as download_count
        FROM resource_downloads rd
        JOIN course_resources cr ON rd.resource_id = cr.id
        WHERE rd.student_id = $2 AND cr.course_id = $1
        GROUP BY rd.student_id, cr.course_id
    )
    SELECT 
        ROUND((sd.download_count::float / tr.total_count) * 100, 2) as material_learning
    FROM student_downloads sd
    JOIN total_resources tr ON sd.course_id = tr.course_id
    WHERE sd.student_id = $2 AND sd.course_id = $1
  `;

  // 查询章节学习次数
  const chapterStudyCountQuery = `
    SELECT 
        COUNT(DISTINCT vpd.video_id) as chapter_study_count
    FROM video_play_duration vpd
    JOIN course_videos cv ON vpd.video_id = cv.id
    WHERE vpd.student_id = $1 AND cv.course_id = $2
    GROUP BY vpd.student_id, cv.course_id
  `;

  // 查询讨论参与度
  const discussionQuery = `
    WITH total_topics AS (
        SELECT 
            course_id,
            COUNT(*) as total_count
        FROM discussion_topics
        WHERE course_id = $1
        GROUP BY course_id
    ),
    student_comments AS (
        SELECT 
            tc.student_id,
            dt.course_id,
            COUNT(*) as comment_count
        FROM topic_comments tc
        JOIN discussion_topics dt ON tc.topic_id = dt.id
        WHERE tc.student_id = $2 AND dt.course_id = $1
        GROUP BY tc.student_id, dt.course_id
    )
    SELECT 
        ROUND((sc.comment_count::float / tt.total_count) * 100, 2) as discussion
    FROM student_comments sc
    JOIN total_topics tt ON sc.course_id = tt.course_id
    WHERE sc.student_id = $2 AND sc.course_id = $1
  `;

  // 查询签到完成率
  const attendanceQuery = `
    WITH total_attendances AS (
        SELECT 
            course_id,
            COUNT(*) as total_count
        FROM course_attendance
        WHERE course_id = $1
        GROUP BY course_id
    ),
    student_attendances AS (
        SELECT 
            ar.student_id,
            ar.course_id,
            COUNT(*) as attendance_count
        FROM attendance_records ar
        WHERE ar.student_id = $2 AND ar.course_id = $1 AND ar.status = '已签到'
        GROUP BY ar.student_id, ar.course_id
    )
    SELECT 
        ROUND((sa.attendance_count::float / ta.total_count) * 100, 2) as attendance
    FROM student_attendances sa
    JOIN total_attendances ta ON sa.course_id = ta.course_id
    WHERE sa.student_id = $2 AND sa.course_id = $1
  `;

  try {
    // 执行查询
    const videoLearningResult = await db.query(videoLearningQuery, [courseId, studentId]);
    const materialLearningResult = await db.query(materialLearningQuery, [courseId, studentId]);
    const chapterStudyCountResult = await db.query(chapterStudyCountQuery, [studentId, courseId]);
    const discussionResult = await db.query(discussionQuery, [courseId, studentId]);
    const attendanceResult = await db.query(attendanceQuery, [courseId, studentId]);

    // 提取结果
    const videoLearning = videoLearningResult.rows[0]?.video_learning || 0;
    const materialLearning = materialLearningResult.rows[0]?.material_learning || 0;
    const chapterStudyCount = chapterStudyCountResult.rows[0]?.chapter_study_count || 0;
    const discussion = discussionResult.rows[0]?.discussion || 0;
    const attendance = attendanceResult.rows[0]?.attendance || 0;

    return {
      videoLearning,
      materialLearning,
      chapterStudyCount,
      discussion,
      attendance
    };
  } catch (error) {
    console.error('查询学生指标失败:', error);
    return {
      videoLearning: 0,
      materialLearning: 0,
      chapterStudyCount: 0,
      discussion: 0,
      attendance: 0
    };
  }
}

// 调用gRPC服务预测成绩
async function predictGrade(studentId: string, courseId: string) {
  // 获取学生指标
  const metrics = await getStudentMetrics(studentId, courseId);
  console.log('学生指标:', metrics);

  // 创建gRPC客户端
  const client = new studentAnalysisProto.student_analysis.StudentAnalysisService(
    'localhost:50051',
    grpc.credentials.createInsecure()
  );

  // 构建请求
  const request = {
    video_learning: metrics.videoLearning,
    material_learning: metrics.materialLearning,
    chapter_study_count: metrics.chapterStudyCount,
    discussion: metrics.discussion,
    attendance: metrics.attendance
  };

  // 调用预测服务
  return new Promise((resolve, reject) => {
    client.PredictGrade(request, (error: any, response: any) => {
      if (error) {
        reject(error);
      } else {
        resolve(response);
      }
    });
  });
}

// 主函数
async function main() {
  await connectDB();

  try {
    // 示例：预测学生ID为'12345'在课程ID为'course001'的成绩
    const studentId = '12345'; // 实际应用中替换为真实的学生ID
    const courseId = 'course001'; // 实际应用中替换为真实的课程ID

    const result = await predictGrade(studentId, courseId);
    console.log('预测结果:', result);
    console.log(`预测成绩等级: ${result.grade}`);
    console.log(`预测置信度: ${result.confidence.toFixed(2)}`);
  } catch (error) {
    console.error('预测失败:', error);
  } finally {
    // 关闭数据库连接
    await db.end();
  }
}

// 运行主函数
main();
```
