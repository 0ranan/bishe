# 计算机科学基础

## 1. 数据结构

### 1.1 数组
数组是一种线性数据结构，它由相同类型的元素组成，并且这些元素在内存中是连续存储的。

### 1.2 链表
链表是一种线性数据结构，它由节点组成，每个节点包含数据和指向下一个节点的指针。

## 2. 算法

### 2.1 排序算法
常见的排序算法包括：冒泡排序、选择排序、插入排序、归并排序、快速排序等。

### 2.2 搜索算法
常见的搜索算法包括：线性搜索、二分搜索、深度优先搜索、广度优先搜索等。

## 3. 计算机网络

### 3.1 OSI七层模型
OSI七层模型包括：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

### 3.2 TCP/IP协议
TCP/IP协议是互联网的基础协议，它包括：网络接口层、网络层、传输层、应用层。
